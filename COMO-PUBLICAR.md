# Cómo sacar el link del catálogo (GitHub Pages, ~10 minutos)
1. Entra a github.com con tu cuenta → botón verde **New** (repositorio nuevo). Nombre: `catalogo-misskatty` · **Public** · sin README → Create repository.
2. En la página del repositorio: **uploading an existing file** → arrastra de esta carpeta: `index.html`, `.nojekyll` y los 3 PDF (`catalogo-cumpleanos-creativos.pdf`, `catalogo-actividades.pdf`, `catalogo-paquetes.pdf`) → **Commit changes**.
3. **Settings → Pages → Branch: main / (root) → Save**.
4. En 1 a 2 minutos el link queda: `https://TU-USUARIO.github.io/catalogo-misskatty/`
   - Los PDF quedan en: `.../catalogo-actividades.pdf`, `.../catalogo-paquetes.pdf` y `.../catalogo-cumpleanos-creativos.pdf`
5. Pruébalo en tu celular y mándate el link por WhatsApp para ver la vista previa.
Para actualizarlo después: volver a subir los archivos cambiados (reemplazan a los anteriores). El archivo ya lleva `noindex` (Google no lo lista).
Nota: `.nojekyll` es un archivo oculto (empieza con punto). Si no lo ves en la carpeta, activa "mostrar archivos ocultos" en el Explorador.
